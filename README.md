# Worldways Web-Developers Ltd website

An original, responsive single-page corporate website for Worldways Web-Developers Ltd.

## Preview

Open `index.html` in a browser. No build step is required.

## Included

- Responsive desktop, tablet and mobile navigation
- Service filtering and interactive process accordion
- Accessible semantic structure and reduced-motion support
- Detailed service, academy, impact and company content
- Responsive project enquiry form UI
- Original commissioned cartoon hero artwork

## Before production

Connect the project form in `script.js` to the company's email, CRM or form-processing endpoint. Replace or supplement the general copy with verified company details, physical address, phone, social links and completed client case studies when available.
